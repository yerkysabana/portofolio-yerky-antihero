# Portofolio Yerky — Anti-Hero Comic Edition

Redesign portofolio pribadi bertema **anti-hero comic** (referensi template `stitch_antihero_comic_portfolio_template`), diimplementasikan dengan **React + Vite + TypeScript**.

## Isi

- Hero interaktif dengan topeng yang matanya mengikuti kursor
- Marquee, panel komik, skill bullet-meter, kartu proyek bergaya stempel
- Mini game zone (3 game canvas: Tembak Target, Tebas Taco, Tangkap Chimichanga)
- Easter egg: Konami code & klik logo 5x

## Menjalankan

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # type-check + production build ke dist/
```

Konten (profil, proyek, pengalaman) bersumber dari portofolio Yerky Syabana dan disusun di `src/data/portfolioData.ts`.
